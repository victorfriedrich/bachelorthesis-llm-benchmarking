# Testing an LLM judge when the human labels are biased

Interactive companion site to my bachelor's thesis in Informatics at TU Munich (2026):
*From Predicting Human Ratings to Measuring True Quality: LLM Accuracy and Bias in Aspect-Based Sentiment Analysis.*

**Live:** [victorfriedrich.github.io/thesis-site](https://victorfriedrich.github.io/thesis-site/) · **Thesis:** [PDF](public/victor-friedrich-bachelor-thesis.pdf)

## What it shows

Hostelworld guests rate seven aspects of a stay, but about 40% give every aspect the same score, so the ratings behave like one overall impression. The thesis scores 342 hostels from their review text with LLMs and tests the scores like a measuring instrument rather than against the guests' ratings.

Main findings:

- LLM aspect scores are far more independent than guests' ratings, and they separate in the same pattern as guests who vary their scores.
- How the model is asked matters. Even with one call per aspect, mentioning all seven aspects in the output schema cancels about 40% of the gain from separate calls.
- The scores need enough reviews to be stable, and the models favour a few last digits, so small score differences carry no information.

The site walks through these results and ends with six lessons for building LLM pipelines and agents.

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000. The full-length version of the site is at `/full`.

## How it's built

- Next.js and React, fully static: every page is prerendered at build time.
- All numbers come from `src/data/site.json`, generated by `export_site_data.py` from the thesis analysis code, which is not part of this repository. No data is fetched at runtime.
- Charts are hand-built SVG components in `src/components/charts.tsx`.

## Deployment

Every push to `main` builds a static export and publishes it to GitHub Pages ([`.github/workflows/pages.yml`](.github/workflows/pages.yml)). The export and the `/thesis-site` base path only apply when `GITHUB_PAGES` is set, so ordinary builds (for example on Vercel) are unaffected.
